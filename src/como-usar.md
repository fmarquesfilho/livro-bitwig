# Como usar este livro

## Demonstrações interativas

Muitos capítulos trazem pequenos sintetizadores que rodam no navegador. Eles
usam a [Web Audio API](https://developer.mozilla.org/pt-BR/docs/Web/API/Web_Audio_API)
e só começam a tocar quando você clica em **▶ Tocar**.

> **Cuidado com o volume.** Comece com o volume do sistema baixo, principalmente
> usando fones de ouvido.

## Caixas "No Bitwig"

Ao final de cada conceito, uma seção **No Bitwig** mostra onde aquele conceito
aparece no software: quais devices usar, quais parâmetros observar e um
exercício prático.

## Manual oficial

O livro não substitui o [manual oficial do Bitwig Studio](https://www.bitwig.com/userguide/latest/).
Sempre que um detalhe de interface for importante, o texto indica a seção
correspondente do manual para consulta.
